# أكاديمية X7do0

منصة تعليمية عربية لتعلّم البرمجة بخطوات واضحة، مع تركيز حالي على أساسيات Python والتمارين العملية وتتبع التقدّم محليًا داخل المتصفح.

## توجّه المشروع

- واجهة عربية فقط، بتصميم **Arabic-first** واتجاه **RTL** كامل.
- لا يوجد مبدّل لغة أو واجهة إنجليزية مستقلة.
- تُعرض أسئلة وتمارين Python بالعربية والإنجليزية معًا لتوضيح المصطلحات والمطلوب، بينما تبقى عناصر الواجهة والتنقل عربية.
- تجربة متجاوبة للكمبيوتر والهاتف.
- المشروع حاليًا موقع Frontend/Static.
- لا توجد حسابات مستخدمين أو Backend أو قاعدة بيانات ضمن النطاق الحالي.

## المزايا الحالية

- مسار حقيقي ومنظّم لتعلّم أساسيات Python.
- دروس عربية وأمثلة برمجية تحافظ على Python syntax والمصطلحات التقنية اللازمة.
- صفحة تمارين تضم 25 سؤالًا ثنائي اللغة.
- تتبع محلي لنسبة الإنجاز وحالة المسار.
- مظهر فاتح وداكن.
- تنقل هاتف يحتوي: الرئيسية، الدروس، التمارين، والمزيد.
