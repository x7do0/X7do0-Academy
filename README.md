# أكاديمية X7do0

منصة تعليمية عربية لتعلّم البرمجة بخطوات واضحة، مع تركيز حالي على أساسيات Python والتمارين العملية وتتبع التقدّم محليًا داخل المتصفح.

## توجّه المشروع

- واجهة عربية فقط، بتصميم **Arabic-first** واتجاه **RTL** كامل.
- لا يوجد مبدّل لغة أو واجهة إنجليزية مستقلة.
- تُعرض أسئلة وتمارين Python بالعربية، مع إبقاء الشيفرات والمصطلحات التقنية الضرورية بصيغتها الصحيحة.
- تجربة متجاوبة للكمبيوتر والهاتف.
- المشروع حاليًا موقع Frontend/Static.
- لا توجد حسابات مستخدمين أو Backend أو قاعدة بيانات ضمن النطاق الحالي.

## المزايا الحالية

- مسار حقيقي ومنظّم لتعلّم أساسيات Python.
- دروس عربية وأمثلة برمجية تحافظ على Python syntax والمصطلحات التقنية اللازمة.
- صفحة تمارين تضم 25 سؤالًا باللغة العربية.
- تتبع محلي لنسبة الإنجاز وحالة المسار.
- مظهر فاتح وداكن.
- تنقل هاتف يحتوي: الرئيسية، الدروس، التمارين، والمزيد.

## التشغيل

يتطلب البناء Node.js وnpm. ثبّت الاعتماديات ثم ولّد صفحات HTML وملف Tailwind CSS:

```bash
npm install
npm run build
```

يولّد أمر البناء الصفحات الثابتة من `src/pages/` والقوالب المشتركة في `src/templates/`، ثم يتحقق من الروابط والملفات المحلية الأساسية. الملفات الناتجة في جذر المستودع وداخل `accounts/` و`courses/` جاهزة للنشر مباشرة على GitHub Pages.

أثناء تعديل CSS يمكن استخدام:

```bash
npm run dev
```

بعد البناء يمكن تشغيل الموقع عبر خادم محلي بسيط أو نشر الملفات الناتجة على GitHub Pages. يُفضّل عدم فتح الصفحات مباشرة بصيغة `file://` لأن ملف النصوص العربي يُحمّل عبر `fetch`.
