# أكاديمية X7do0

منصة تعليمية عربية لتعلّم البرمجة بخطوات واضحة، مع تركيز حالي على أساسيات Python والتمارين العملية وتتبع التقدّم محليًا داخل المتصفح.

## توجه المشروع

- واجهة عربية فقط.
- تصميم Arabic-first مع دعم كامل لاتجاه RTL.
- تجربة متجاوبة للكمبيوتر والهاتف.
- موقع Frontend/Static في المرحلة الحالية.
- لا توجد حسابات مستخدمين أو Backend أو قاعدة بيانات ضمن النطاق الحالي.

## المزايا الحالية

- مسار منظم لتعلّم أساسيات Python.
- دروس وأمثلة وتمارين برمجية.
- صفحة تدريب تضم أسئلة عملية.
- تتبع محلي لنسبة الإنجاز.
- مظهر فاتح وداكن.
- تنقل مخصص للهاتف.

## التشغيل

يتطلب البناء Node.js وnpm. ثبّت الاعتماديات ثم ولّد صفحات HTML وملف Tailwind CSS:

```bash
npm install
npm run build
```

يولّد أمر البناء الصفحات الثابتة من `src/pages/` والقوالب المشتركة في `src/templates/`، ثم يتحقق من الروابط والملفات المحلية الأساسية. الملفات الناتجة في جذر المستودع وداخل `accounts/` و`courses/` جاهزة للنشر مباشرة على GitHub Pages.

أثناء تعديل CSS يمكن استخدام:

```bash
npm run dev
```
