# أكاديمية X7do0

![واجهة أكاديمية X7do0](assets/preview.png)

منصة عربية لتعلّم البرمجة بالتطبيق، تجمع الشرح المختصر والدروس والتمارين العملية ضمن تجربة واحدة واضحة. الأكاديمية مصممة حتى تتوسع إلى أكثر من لغة ومسار برمجي بدل ما تكون مرتبطة بدورة واحدة فقط.

[زيارة الأكاديمية](https://x7do0.github.io/X7do0-Academy/) · [الدورات](https://x7do0.github.io/X7do0-Academy/courses/index.html)

## المسارات

### أساسيات بايثون — متاح

المسار الحالي المكتمل داخل الأكاديمية. يبدأ من الأساسيات ويتدرج عبر الدروس والأمثلة والتمارين العملية.

- نظرة عامة تفاعلية على المواضيع الأساسية.
- دروس مرتبة مع أمثلة وملفات للمراجعة والتطبيق.
- 25 تمرينًا وتحديًا برمجيًا.
- حفظ تقدّم التمارين محليًا على جهاز المستخدم.

### C++ — قيد الإعداد

مسار مستقل لتعلّم أساسيات C++ بنفس أسلوب الأكاديمية: شرح واضح، أمثلة عملية، ثم تطبيق وتمارين.

### C++ OOP — مخطط له

مسار منفصل للبرمجة كائنية التوجه باستخدام C++، حتى يبقى الانتقال من الأساسيات إلى OOP واضحًا ومنظمًا.

### لاحقًا

الأكاديمية قابلة لإضافة مسارات أخرى مثل C# ومواضيع برمجية وتقنية إضافية حسب المحتوى الذي يتم تجهيزه.

## تجربة التعلّم

- واجهة عربية كاملة واتجاه RTL.
- الأكواد والمخرجات تبقى باتجاه LTR.
- مظهر فاتح وداكن.
- تنظيم كل دورة داخل مسار مستقل.
- دروس وتمارين وتقدّم محفوظ محليًا عندما يحتاج المسار ذلك.
- تصميم يسمح بإضافة دورات جديدة بدون ربط المنصة بلغة واحدة.

## هيكل المحتوى

الدورات موجودة داخل `courses/`، وكل لغة أو مسار له مجلده الخاص. مسار بايثون الحالي موجود في:

```text
courses/
└── python/
    ├── index.html
    ├── lessons/
    └── practice/
```

وعند إضافة أي دورة جديدة تُبنى كمسار مستقل بنفس الفكرة بدل خلط محتواها مع بايثون.
